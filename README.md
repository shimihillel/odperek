# עוד פרק אחד — Reimagined

גרסה חדשה, מינימליסטית ושקטה ליומן הקריאה.

## העלאה ל-GitHub Pages
1. חלצי את קובץ ה-ZIP.
2. העלי את כל הקבצים לתיקיית הבסיס של ה-Repository.
3. ב-GitHub היכנסי אל **Settings → Pages**.
4. בחרי **Deploy from a branch**, את הענף `main`, ואת התיקייה `/root`.
5. פתחי את כתובת האתר והוסיפי למסך הבית באייפון.

## מה נשמר
- הספר שקוראים עכשיו וכריכה אמיתית מהגלריה.
- מחשבות חופשיות תוך כדי קריאה.
- ספרים שסיימת: דירוג, מהירות קריאה, רמת לוהט וכמה מילים.
- ספרים שנטשת וסיבת הנטישה.
- מדף כריכות עם חיפוש וסינון.
- גיבוי ושחזור מלאים, כולל הכריכות.

המידע נשמר מקומית במכשיר. כריכות נשמרות ב-IndexedDB כדי לא להעמיס על localStorage.
הגרסה יודעת לקרוא ולפשט מידע מהגרסאות הקודמות המשתמשות במפתח `od-perek-ehad-v5`.
